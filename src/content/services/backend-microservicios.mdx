# Backend & Microservicios

Diseño sistemas empresariales pensados para crecer utilizando arquitectura hexagonal y patrón MVC. Desde modelado de bases de datos relacionales hasta módulos desacoplados, cada componente sigue principios SOLID.

## ¿Qué incluye?

- API REST escalable y versionada
- Arquitectura hexagonal / limpia
- Bases de datos relacionales (PostgreSQL, MySQL) y NoSQL (MongoDB)
- Contenerización con Docker
- Testing automatizado con JUnit
